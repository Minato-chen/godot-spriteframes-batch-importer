# SpriteFrames 批量导入器

[English](README.md) | **简体中文**

这是一个 Godot 4 编辑器插件，用于按照规则从 Sprite Sheet 批量生成带名称的 `SpriteFrames` 资源。

插件提供中英文界面、可缩放的实时预览、彩色选区、可视化状态与方向配置、状态增删、循环设置、帧数设置以及自定义起始列。修改配置后，预览会立即更新。多个状态选择同一格时会使用对比色叠加，并显示白色边框和交叉线，便于识别 Hit 与 Death 等共享选帧。

## 安装

将仓库中的插件目录复制到项目的：

```text
res://addons/spriteframes_batch_importer/
```

然后打开 **项目 → 项目设置 → 插件**，启用 **SpriteFrames Batch Importer**。

启用后，编辑器右侧会出现名为 **帧导入** 的 Dock。

## 语言切换

Dock 顶部可以选择：

- 中文
- English

插件启用时会根据 Godot 编辑器语言确定初始界面语言。Dock 标签在本次启用期间保持该初始语言；Dock 内的界面语言可随时手动切换。

动画状态名和方向名不会自动翻译，因为它们会用于生成最终动画名称。

## 使用方法

1. 在 Godot 的 **文件系统** 面板中选中 PNG、WebP 或 SVG Sprite Sheet。
2. 点击插件中的 **使用文件系统中选中的 Sprite Sheet**。
3. 设置帧宽、帧高、边距与帧间隔。
4. 添加或删除动画状态，并设置名称、帧数、循环和起始列。
5. 添加或删除方向，并设置每个方向对应的行号。
6. 展开实时预览，缩放并检查彩色选区是否正确。
7. 确认位于 `res://` 内的 `.tres` 输出路径。
8. 点击 **生成 SpriteFrames**。

默认动画速度为 8 FPS，即每帧持续约 0.125 秒。FPS 只影响生成后的 `SpriteFrames` 播放速度，彩色切片预览本身不会播放动画。

每个状态默认勾选 **使用默认 FPS**。取消勾选后可以填写该状态自己的速度；状态速度会应用于它的所有方向，例如全部 `attack_*` 动画共用 Attack 状态 FPS。

选中图集后，输出路径默认与图集位于同一文件夹，并在原文件名后附加 `_frames.tres`。例如 `res://art/Mushrooms_16x16.png` 会默认输出为 `res://art/Mushrooms_16x16_frames.tres`。

输出路径必须位于 `res://` 内，并使用 `.tres` 扩展名。插件会在可行时创建缺失的输出文件夹，并在生成前检查输出位置是否可写。

覆盖已有 `.tres` 时，插件会先要求确认；确认后会清除旧动画并重建当前配置，同时更新 Godot 已加载的资源，避免动画编辑器继续显示旧选帧。若同路径已有的不是 `SpriteFrames` 资源，插件不会覆盖它。

## 默认设置

默认动画状态为：

```text
idle    4 帧  循环
walk    4 帧  循环
attack  4 帧  不循环
hit     4 帧  不循环
death   4 帧  不循环
```

默认方向与行号为：

```text
down   1
left   2
right  3
up     4
```

行号和列号均从 `0` 开始：如果 Sprite Sheet 没有标题行，第一个方向通常填写 `0`；如果第一行是标题，第一个方向通常填写 `1`。例如有一行标题时，四个方向可以依次使用 `1、2、3、4`。越界提示中的帧序号则从 `1` 开始，符合通常的计数习惯。

## 状态配置逻辑

每个状态包含以下信息：

```text
名称,帧数,是否循环[,起始列]
```

例如：

```text
idle,4,true
walk,4,true
attack,4,false
hit,4,false
death,4,false
```

当起始列为 `-1` 时，该状态会自动接在上一个状态之后。

如果状态之间存在空列，或者多个动画需要重复使用同一组选帧，可以手动指定起始列：

```text
idle,4,true,0
walk,6,true,5
attack,3,false,12
```

例如 Hit 和 Death 共用一组图片时，可以让它们使用相同的起始列，但设置不同的帧数。

## 方向配置逻辑

每个方向包含：

```text
方向名,所在行
```

例如：

```text
down,1
left,2
right,3
up,4
```

最终动画名称采用 `状态_方向` 格式，例如：

```text
idle_down
walk_left
attack_right
death_up
```

## 支持的 Sprite Sheet 布局

当前版本适用于以下规则布局：

- 动画状态横向排列。
- 每个状态占据连续列。
- 不同方向位于可配置的行。
- 所有帧使用统一尺寸。
- 可以设置边距、间隔和起始列。

以下布局暂不属于快速规则模式：

- 帧完全分散在不同位置。
- 旋转帧。
- 不规则打包的 Texture Atlas。
- 每个动画都采用完全不同的排列方式。

这类素材需要逐帧映射功能，当前版本暂未提供。

## 注意事项

- 输出路径必须位于 `res://` 内。
- 输出文件必须使用 `.tres` 扩展名；同名的非 `SpriteFrames` 资源不会被覆盖。
- 生成前请用实时预览确认选区。
- 如果某个状态与前一个状态不连续，请手动填写起始列。
- 非循环动画可以取消 **循环** 选项。
- 已经生成的 `.tres` 不会因修改插件默认值而自动改变，需要重新生成。
